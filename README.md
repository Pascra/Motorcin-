## CONTROLES MOTOR

- Mantener click derecho + "WASD" para moverse libremente.
- Mantener click derecho + "Scroll Ratón" para hacer zoom.
- "TAB" para alternar modo WIREFRAME.
- "F" Auto focus.
- "Drag and Drop" para añadir un modelo a la escena.

## COMENTARIOS ADICIONALES

El motor no carga bien los fbx y se ven como planos con texturas, aunque la cámara funciona correctamente.
